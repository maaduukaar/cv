## <SolarIcon name="pin" /> Обзор проекта и ТЗ

**pdf2audiobook** устраняет рутинные сложности создания аудиокниги из PDF: выбор голоса, пропуск оглавления, разбиение большой книги на безопасные TTS-запросы и восстановление после обрыва сети. Утилита использует Microsoft Edge Text-to-Speech через пакет `edge-tts`: требуется подключение к интернету, но API-ключи и платные сервисы не нужны.

В проекте есть два дополняющих друг друга режима:

- интерактивный режим по умолчанию находит PDF в рабочей папке и ведёт пользователя по настройкам с клавиатурной навигацией;
- CLI поддерживает прямую конвертацию, тестовые запуски, добавление обложки и поиск голосов для повторяемых сценариев.

### Цели реализации

- Извлекать текст из обычных PDF и автоматически включать OCR для страниц-сканов.
- Генерировать речь порциями, не выходящими за настраиваемое ограничение TTS-запроса.
- Показывать прогресс генерации, повторять неудачные запросы и продолжать работу после остановки.
- Позволять выбрать начальную страницу, язык, голос, имя результата и обложку прямо в мастере.
- Сохранить каждую возможность в явных CLI-подкомандах для автоматизации и тестирования.

## <SolarIcon name="lightbulb" /> Сложная инженерная задача: автоматический OCR fallback для сканированных PDF

::: details <SolarIcon name="code" /> Открыть логику выбора OCR и реализацию

### Проблема

`pypdf` извлекает текст, только когда в PDF есть текстовый слой. Сканированная книга может выглядеть нормально в просмотрщике, но возвращать пустое значение из `extract_text()` на каждой странице. Отдельный режим только для OCR заставил бы пользователя заранее определять тип документа и неоправданно нагружал бы обработку смешанных PDF.

### Реализация

Стандартное извлечение остаётся быстрым маршрутом по умолчанию. Для каждой пустой страницы утилита лениво инициализирует опциональные OCR-зависимости, рендерит только эту страницу в масштабе 2x, передаёт изображение в RapidOCR и использует распознанные строки как текст страницы. Движок OCR создаётся один раз и переиспользуется для следующих страниц-сканов.

```python
page_text = reader.pages[i].extract_text()

if not page_text or not page_text.strip():
    if has_ocr:
        if not ocr_engine:
            ocr_engine = RapidOCR()

        doc = pdfium.PdfDocument(pdf_path)
        page = doc[i]
        image = page.render(scale=2.0).to_pil()
        result, _ = ocr_engine(np.array(image))

        if result:
            page_text = "\n".join(item[1] for item in result)
```

### Поведение без OCR-зависимостей

Пакеты для OCR импортируются условно, поэтому для обычных текстовых PDF они не обязательны. Если извлечь текст не удалось, а поддержка OCR не установлена, программа завершает работу с понятной подсказкой о двух пакетах, необходимых для сканированных документов.

### Результат

Одна команда конвертации работает с обычными, сканированными и смешанными документами. OCR включается только там, где он нужен, поэтому оставшиеся страницы книги обрабатываются быстрым путём текстового слоя.

:::

## <SolarIcon name="bolt" /> Технические решения и ключевые сложности

::: warning <SolarIcon name="danger" /> Длинная книга может не поместиться в один TTS-запрос или прерваться в процессе

Отправка книги целиком делает ошибку дорогой и не оставляет точки восстановления. Сетевым вызовам также нужно достаточно времени на большие фрагменты, но бесконечно ожидать нельзя.

:::

::: tip <SolarIcon name="lightbulb" /> Решение: батчи, видимый прогресс и продолжение запуска

Текст разбивается на части до `35_000` символов по умолчанию с приоритетом границ предложений. Каждая часть сохраняется как `temp_batch_N.mp3`. При следующем запуске непустые готовые файлы пропускаются, а настраиваемые таймауты и повторы изолируют временные ошибки. В финале батчи склеиваются и удаляются, если пользователь не выбрал их сохранение.

:::

::: warning <SolarIcon name="danger" /> Каталог Edge содержит слишком много языков и голосов для одного меню терминала

Жёстко заданный короткий список голосов быстро устаревает и ограничивает пользователя. Одновременный вывод всех динамических вариантов делает навигацию с клавиатуры неудобной.

:::

::: tip <SolarIcon name="lightbulb" /> Решение: динамический каталог, фильтр языка и постраничный выбор

Мастер загружает актуальный каталог голосов Edge, показывает распространённые коды языков первыми, фильтрует голоса по выбранному языку и выводит длинные списки по десять вариантов с переходами вперёд и назад. Тот же механизм используется для PDF, MP3 и изображений обложек.

:::
