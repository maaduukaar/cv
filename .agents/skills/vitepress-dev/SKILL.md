# 🚀 Запуск и управление локальным сервером VitePress

Данный скилл содержит инструкции для локального запуска сервера разработки, сборки и проверки сайта/резюме на базе **VitePress**.

---

## 🛠️ Основные команды

| Команда | Описание |
|---|---|
| `npm run docs:dev` | Запуск сервера разработки с поддержкой Hot Reload |
| `npm run docs:build` | Проверка синтаксиса и сборка продакшен-версии в `.vitepress/dist` |
| `npm run docs:preview` | Запуск локального сервера для предпросмотра собранного бандла |

---

## 🏃 1. Запуск локальной версии (Dev Server)

Для запуска используйте инструмент `run_command` в фоновом режиме:

```bash
npm run docs:dev
```

* **Рабочая директория (Cwd):** Корень репозитория (`c:\dev\CV`).
* **Ожидаемый результат:** Сервер поднимется на `http://localhost:5173` (или `http://localhost:5174`, если порт занят).
* **Параметры запуска:** Запускать как фоновое задание с задержкой `WaitMsBeforeAsync: 3000`.

---

## 🔍 2. Проверка состояния сервера

1. Проверьте лог работы фонового задания или его статус через `manage_task`.
2. Чтобы убедиться, что сервер работает и отвечает без ошибок, можно выполнить запрос или открыть адрес `http://localhost:5173` в браузере.

---

## 📦 3. Валидация и Сборка (Build Check)

Перед коммитом или деплоем всегда рекомендуется проверять корректность синтаксиса и отсутствие битых ссылок:

```bash
npm run docs:build
```

Если сборка проходит без ошибок, все Markdown-файлы и Vue-компоненты валидны.

---

## ⚠️ Решение частых проблем

* **Порт 5173 уже занят:** VitePress автоматически выберет следующий свободный порт (`5174`, `5175` и т.д.). Проверьте лог запуска.
* **Ошибка отсутствующих зависимостей (`node_modules`):** Выполните `npm install` перед запуском.
